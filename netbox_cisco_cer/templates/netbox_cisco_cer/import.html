How syncing works
  • In {% if cer_admin_url %}CER Admin {% else %}CER Admin{% endif %}, open the ERL list (National E911 or Conventional) and click Export. Upload the CSV unchanged.
  • ERLs are matched by name, so re-importing a newer export updates them in place. National E911 ERLs import as Migrated, Conventional ones as In CER. The Default ERL is skipped.
  • New ERLs are matched to a Site by name prefix (ADMN 0-2 becomes ADMN), then by street address. ERLs with no match are imported without a site.
  • Start with Dry run to preview the changes. Nothing is saved until you untick it.
